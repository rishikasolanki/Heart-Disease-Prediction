# Heart Disease Prediction

## Overview
This project uses Machine Learning techniques to predict whether a patient is likely to have heart disease based on medical attributes. The workflow includes data preprocessing, feature scaling, model training, evaluation, and visualization.

## Dataset
- Heart Disease UCI Dataset (Kaggle)

## Objectives
- Clean and preprocess data
- Apply feature scaling
- Train Logistic Regression and Decision Tree models
- Evaluate model performance
- Generate Confusion Matrix and ROC Curve

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data Cleaning
2. Feature Scaling
3. Train-Test Split
4. Model Training
5. Prediction
6. Accuracy Evaluation
7. Confusion Matrix Visualization
8. ROC Curve Analysis

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Score

## Results
Successfully predicted the presence of heart disease with high classification accuracy and visualized performance using confusion matrix and ROC curve.
